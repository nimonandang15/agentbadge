AgentBadge

A free badge NFT for Binance Agent ID holders. One badge per wallet, gas only. Your Agent ID is checked on-chain — no sign-up, no server, no data collected.

This demo build has no contract address set yet. After deployment, set CONTRACT_ADDRESS in app.js.

How it works: the AgentBadge contract calls balanceOf on the Agent ID registry (0x60B9…022F) to prove you hold an Agent ID, then mints exactly one badge to your wallet. Minting is free apart from BSC gas (~0.000005 BNB at 0.05 gwei). The mint transaction is sent only when you click the button and confirm it in your own wallet — nothing is ever auto-signed and no token approvals are requested. Contract source is open and verifiable on BscScan.
